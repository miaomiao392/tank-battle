# 坦克大战 (Tank Battle)

一个纯 HTML5 Canvas + JavaScript 实现的经典坦克大战游戏，单文件、零依赖，打开 `index.html` 即可游玩。

## 玩法

- 驾驶黄色坦克消灭所有敌方坦克即可进入下一关
- **保护底部的金色基地**，基地被摧毁即游戏结束
- 敌方坦克数量随关卡增加，速度也会略微提升

## 操作

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 地形说明

- 🟧 **砖墙**：可被子弹打掉
- ⬜ **钢墙**：普通子弹打不穿
- 🟦 **水域**：坦克无法通过，子弹可以飞过
- 🟩 **草丛**：遮挡视线，坦克可以自由穿过
- 🟨 **金色基地**：必须守护的目标

## 运行

无需安装任何依赖，直接用浏览器打开 `index.html` 即可。也可以本地起个服务：

```bash
npx serve .
# 或
python -m http.server 8000
```

## 技术

- 纯原生 HTML / CSS / JavaScript，无框架无依赖
- Canvas 2D 渲染，约 60 FPS 游戏循环
- 敌人 AI：朝基地或玩家方向移动的加权随机决策
